The cockpitLe cockpit座艙

Four instruments, one windowQuatre instruments, une fenêtre四項儀表，一個視窗

Four separate apps used to answer four halves of the same question. Claude Cockpit puts them on one dashboard: how much quota is left, what today actually cost, what your tooling saved, and what Claude Code is working with. Quatre apps distinctes répondaient jusqu'ici à quatre moitiés de la même question. Claude Cockpit les réunit sur un seul tableau de bord : combien de quota reste-t-il, ce que la journée a réellement coûté, ce que l'outillage a économisé, et avec quoi Claude Code travaille. 過去要四個獨立應用程式，才能回答同一個問題的四個面向。Claude Cockpit 把它們放進同一個儀表板：還剩多少配額、今天實際花了多少、工具省下了多少，以及 Claude Code 手上有哪些資源。

Not just how much is gone — where it landsPas seulement ce qui est consommé — où ça atterrit不只是用掉多少，而是會落在哪裡

Claude Cockpit reads the same usage endpoint Claude Code itself reads, so the percentages match /usage exactly. It then adds the one number Anthropic never gives you: whether today's pace makes it to the reset. Claude Cockpit lit l'endpoint d'usage que Claude Code lit lui-même : les pourcentages correspondent exactement à /usage. Il y ajoute le chiffre qu'Anthropic ne donne jamais : si le rythme du jour tiendra jusqu'à la réinitialisation. Claude Cockpit 讀取的，正是 Claude Code 自己讀取的用量端點，因此百分比與 /usage 完全一致。它再補上 Anthropic 從不提供的那個數字：今天的節奏能不能撐到重置。

  • Both Anthropic windows. The 5-hour session and the 7-day quota, each with its reset countdown, its current rate in %/h and the sustainable rate that would land exactly on the limit. Les deux fenêtres Anthropic. La session de 5 h et le quota de 7 jours, chacun avec son compte à rebours, son rythme actuel en %/h et le rythme tenable qui atterrirait pile sur la limite. 兩個 Anthropic 視窗。5 小時工作階段與 7 天配額，各自標示重置倒數、目前每小時百分比，以及剛好落在上限的可持續速率。
  • Projection to the reset, and a daily budget. Where the week ends if nothing changes, and how much you can spend today to keep an even pace. A window that just opened says so instead of extrapolating a three-minute burst into a habit. Projection jusqu'à la réinitialisation, et budget quotidien. Où la semaine finit si rien ne change, et ce que vous pouvez dépenser aujourd'hui pour tenir un rythme régulier. Une fenêtre à peine ouverte le dit, au lieu d'extrapoler trois minutes d'activité en habitude. 推算至重置，並給出每日預算。若一切不變本週會停在哪裡，以及今天可以用多少才能維持穩定節奏。剛開啟的視窗會直說，而不會把三分鐘的爆量外推成長期習慣。
  • One meter per model. Each model-specific weekly limit gets its own row, so a limit you are about to hit never hides behind a comfortable overall percentage. Une jauge par modèle. Chaque limite hebdomadaire propre à un modèle a sa ligne : une limite sur le point d'être atteinte ne se cache jamais derrière un pourcentage global confortable. 每個模型一條計量。每項模型專屬的每週上限都有自己的一列，即將觸頂的限制不會被看似寬裕的整體百分比掩蓋。

Percentages hide what you actually spentLes pourcentages masquent la dépense réelle百分比掩蓋了實際的花費

Every Claude Code answer is written to a transcript in ~/.claude/projects. Claude Cockpit scans them incrementally and turns them into exact token counts and a priced cost — nothing estimated, nothing reconstructed. Chaque réponse de Claude Code est écrite dans un transcript sous ~/.claude/projects. Claude Cockpit les parcourt de façon incrémentale et les transforme en comptage exact de tokens et en coût valorisé — rien d'estimé, rien de reconstruit. Claude Code 的每則回覆都會寫入 ~/.claude/projects 下的記錄檔。Claude Cockpit 以增量方式掃描它們，轉換成精確的 token 計數與計價後的成本——不估算，也不重建。

  • Four ways to slice it. Tokens and cost by model, by project, by agent and by skill — so you can see which sub-agent or which repository is quietly carrying the bill. Quatre découpages. Tokens et coût par modèle, par projet, par agent et par skill — de quoi voir quel sous-agent ou quel dépôt porte discrètement la facture. 四種切分方式。依模型、專案、代理與技能分列 token 與成本——一眼看出是哪個子代理或哪個儲存庫悄悄扛下了帳單。
  • A daily chart, and the sessions behind it. The day-by-day series over any range, with filters on models and projects, and a session list you can open to see the turns one by one. Un graphique quotidien, et les sessions derrière. La série jour par jour sur n'importe quelle période, avec des filtres par modèle et par projet, et une liste de sessions que l'on ouvre pour voir les tours un à un. 每日圖表，以及背後的工作階段。任意期間的逐日數列，可依模型與專案篩選，並附可展開的工作階段清單，逐輪檢視。
  • Pricing you control. The rate table for each model family is editable and stored locally, so the cost stays right when Anthropic's prices move or when your own accounting differs. Une tarification que vous maîtrisez. La table de tarifs de chaque famille de modèles est modifiable et stockée en local : le coût reste juste quand les prix d'Anthropic bougent ou quand votre comptabilité diffère. 由你掌控的計價。各模型家族的費率表可編輯並存於本機，因此當 Anthropic 調價、或你的帳務口徑不同時，成本依然正確。

Si rtk est installé, Claude Cockpit ouvre son history.db en lecture seule et en fait un tableau de bord d'économies. Tokens économisés aujourd'hui, la série des sept jours en graphique, et le total depuis l'installation de rtk — avec le taux de compression qui les a produits. 三種時間尺度。今日省下的 token、七日數列圖表，以及自安裝 rtk 以來的累計總量——並附上達成這些數字的壓縮比。

How it worksComment ça marche運作方式

Everything is read locallyTout est lu en local一切都在本機讀取

Claude Cockpit reads files that are already on your Mac. It makes exactly two kinds of network call, both of which you can name, and neither of which sends your data anywhere. Claude Cockpit lit des fichiers déjà présents sur votre Mac. Il ne fait que deux types d'appels réseau, tous deux nommables, et aucun n'envoie vos données où que ce soit. Claude Cockpit 讀取的，都是你 Mac 上已有的檔案。它只發出兩種網路請求，兩者都說得出名字，而且都不會把你的資料送往任何地方。
